# DevOps Lab - Assignment 1

## Title
Git Setup and Basic Workflow

## Objective
To understand the basic Git workflow by creating a file,
checking repository status, staging changes, committing
the changes, and synchronizing with a remote repository.

## Tools Used
- Git
- GitHub
- macOS Terminal

## Procedure
1. Create a README.md file.
2. Check the repository status using git status.
3. Stage the README file using git add.
4. Commit the changes using git commit.
5. Verify the commit using git log.
6. Push the changes to the remote GitHub repository.

## Result
The basic Git workflow was demonstrated using a README file.
