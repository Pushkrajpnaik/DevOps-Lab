# Assignment 11: Docker Compose for Multi-Container App

## Objective
To deploy a Flask web application and Redis service using Docker Compose.

## Files
- app.py: Flask application with a Redis-backed visit counter.
- requirements.txt: Python dependencies.
- Dockerfile: Flask application image definition.
- docker-compose.yml: Defines Flask, Redis, networking, and persistent Redis storage.

## Procedure
1. Created the Flask application and dependencies.
2. Created the Dockerfile.
3. Defined the web and Redis services in docker-compose.yml.
4. Started both services using Docker Compose.
5. Verified service status and tested the application.

## Result
Successfully ran a Flask and Redis multi-container application using Docker Compose.
