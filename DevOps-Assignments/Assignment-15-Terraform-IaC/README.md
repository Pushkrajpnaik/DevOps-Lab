# Assignment 15: Terraform Infrastructure as Code

## Objective
Use Terraform and the Local provider to create, update, and destroy a local text file.

## Implementation
1. Checked the Terraform version.
2. Initialized the working directory using terraform init.
3. Previewed changes using terraform plan.
4. Created the file using terraform apply.
5. Updated the file content and applied the changes.
6. Removed the managed resource using terraform destroy.

## Commands
- terraform --version
- terraform init
- terraform plan
- terraform apply
- terraform destroy

## Result
Terraform managed the lifecycle of a local file through configuration code.
